Frequently asked questions

Only Android, or iOS too?

We can build both. For field teams that all use Android phones, starting with Android is often faster and more economical.

Can the app work where there is no signal?

Yes. Data is stored on the device and sent automatically when a connection is available, which suits mine sites and estates.

How long does it take?

It depends on features and integrations. We usually start with a first version of the core features, test it in the field, then expand step by step.

Who owns the code and the data?

The data belongs to the client, and the app can run on the client's server or private cloud. Code ownership is set out in the contract.

Is there support after release?

Yes. We provide fixes, updates for new Android versions, and further feature development.

Have a process you want to move into an app?

Tell us the workflow and who the users are. The first discussion is free.
